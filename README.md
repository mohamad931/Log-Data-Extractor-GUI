# Log-Data-Extractor-GUI
A GUI desktop application built with CustomTkinter to parse and extract unique emails and phone numbers from log files.
How to use:
# Features
- Built with modern GUI with CustomTkinter.
- Processing log files very fast using regular expressions(Regex).
- Program built in a flexible and uncomplicated way.
- Store the results in external file in name (results.txt).
# Executable Download
- You can download it as ready-to-use Windows '.exe' application directly from[Releases Section](https://github.com/mohamad931/Log-Data-Extractor-GUI/releases)
# How to Run from Source
1. Clone the repository:
 '''bash
 git clone https://github.com/mohamad931/Log-Data-Extractor-GUI.git

2. Install dependencies:
'''bash
pip install -r requirements.txt

3. Run the application:
'''bash
python Log_Data_Extractor.py
